# Project 1 functional boundary

Included: branded website and products, online sales, six order masters, customers, franchise management and retail stores, Communication Centre, reports, users/roles, integrations, settings, audit/logs, automation, backup/recovery, system maintenance and Page Manager.

Excluded by specification: production operations, unified finance, payroll, HR, POS and a separate franchise portal. Franchise work is managed inside the single admin cPanel.

The implementation-to-specification mapping and acceptance criteria are maintained in `docs/IMPLEMENTATION-MATRIX.md`.

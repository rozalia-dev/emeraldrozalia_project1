# Visual foundation evidence

Task P2.1 records the shared visual tokens extracted from the approved homepage references in `new project image/home page 1.png` and `home page 2.png`, and the supplied Visual Developer Guide.

The tokens live in `public/css/app.css` and cover:

- dark ink/page/panel surfaces and Emerald green accents
- gold heritage borders and eyebrow text
- cream/white primary text and muted secondary text
- sans-serif UI and serif display typography
- responsive display/type scales
- spacing, card radii, content gutter and tablet/mobile breakpoints

This is a shared foundation, not a claim that every screen is pixel-verified. Artwork shown in the references still requires the original source image archive before visual acceptance.
